# patFiveCat 本地演示部署文档

本文档说明如何下载、初始化、启动和排查宠友邻 `patFiveCat` 项目。当前项目定位为本地演示 MVP，默认使用 Mock Store，即使不连接数据库也能体验主要流程。

## 1. 仓库地址

SSH：

```bash
git@github.com:PinocchioCat/FiveCat.git
```

HTTPS：

```bash
https://github.com/PinocchioCat/FiveCat.git
```

## 2. 环境要求

推荐 Windows 环境，项目脚本以 PowerShell 为主。

必需：

- Git
- Python 3.12
- Node.js 20+
- npm

可选：

- Docker Desktop，用于启动 PostgreSQL + PostGIS + Redis

检查命令：

```powershell
git --version
python --version
node --version
npm --version
docker --version
```

## 3. 下载项目

```powershell
cd D:\workspace
git clone git@github.com:PinocchioCat/FiveCat.git patFiveCat
cd .\patFiveCat
```

如果使用 ZIP 下载，也可以直接解压后进入目录；但若后续需要提交代码，建议使用 `git clone`。

## 4. 首次初始化

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-local.ps1
```

脚本会执行：

- 若 `frontend/.env` 不存在，从 `.env.example` 复制生成
- 若 `backend/.env` 不存在，从 `.env.example` 复制生成
- 执行 `python -m pip install -e .` 安装后端依赖
- 若 `frontend/node_modules` 不存在，执行 `npm.cmd install`

## 5. 启动演示服务

推荐方式：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1
```

默认启动：

- 后端：`http://127.0.0.1:8000/`
- Swagger：`http://127.0.0.1:8000/docs`
- 前端：`http://127.0.0.1:5174/`

日志与 PID：

- `.logs/backend.out.log`
- `.logs/backend.err.log`
- `.logs/frontend.out.log`
- `.logs/frontend.err.log`
- `.logs/backend.pid`
- `.logs/frontend.pid`

## 6. 启动数据库和 Redis

如果希望同时启动基础设施：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1 -WithInfra
```

该命令会执行 Docker Compose，启动：

- PostgreSQL + PostGIS：`localhost:5432`
- Redis：`localhost:6379`

数据库默认配置：

- DB：`petneighbor`
- User：`petneighbor`
- Password：`petneighbor`

初始化脚本：

```text
backend/sql/init_postgis.sql
```

说明：当前业务默认仍以 Mock Store 为主，数据库主要用于验证基础设施和后续真实仓储接入；宠物新增逻辑会尝试写入 PostgreSQL 作为演示。

## 7. 停止服务

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\stop-local.ps1
```

该脚本会读取 `.logs/*.pid` 并停止本项目启动的前后端服务。

如果使用了 `-WithInfra`，可额外停止 Docker：

```powershell
docker compose down
```

保留数据卷时不要加 `-v`。若要清空数据库数据：

```powershell
docker compose down -v
```

## 8. 手动启动方式

### 8.1 后端

```powershell
cd .\backend
python -m pip install -e .
copy .env.example .env
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### 8.2 前端

新开一个终端：

```powershell
cd .\frontend
npm install
copy .env.example .env
npm run dev -- --host 127.0.0.1 --port 5174
```

### 8.3 基础设施

```powershell
docker compose up -d
```

## 9. 环境变量说明

### 9.1 后端

常用配置位于 `backend/.env`：

- `APP_NAME`
- `API_PREFIX=/api/v1`
- `USE_MOCK_DATA=true`
- `POSTGRES_DSN`
- `REDIS_URL`
- `ALLOWED_ORIGINS`

当前默认 `USE_MOCK_DATA=true`，因此 API 主要使用内存数据。

### 9.2 前端

常用配置位于 `frontend/.env`：

- `VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1`
- `VITE_AMAP_KEY`

若未配置 `VITE_AMAP_KEY`，地图取点组件会退化为演示视图，不影响主要页面操作。

## 11. 推荐演示路径

1. 首页：确认未登录和登录后首页保持一致。
2. 登录：选择宠物主人登录。
3. 宠物主人：进入找服务、我的订单、发单大厅、个人中心。
4. 切换身份：切换为兼职铲屎官。
5. 铲屎官：进入任务大厅，查看右侧详情并点击立即抢单。
6. 铲屎官：进入接单记录，查看状态 tabs、收入统计和服务卡片。
7. 社区：发布图文动态，删除自己的帖子。
8. 客服：打开右下角浮窗发送消息。

## 12. 常见问题

### 12.1 端口被占用

检查端口：

```powershell
Get-NetTCPConnection -LocalPort 5174 -ErrorAction SilentlyContinue
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue
```

如果当前 PowerShell 不支持 `Get-NetTCPConnection`，可使用：

```powershell
netstat -ano | Select-String ':5174|:8000'
```

### 12.2 依赖缺失

重新执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-local.ps1
```

### 12.3 前端请求失败

检查：

- 后端是否运行在 `8000`
- `frontend/.env` 中 `VITE_API_BASE_URL` 是否正确
- `.logs/backend.err.log` 是否有异常

前端 API 客户端在部分请求失败时会回退到本地 Mock 数据。

### 12.4 Docker 启动失败

确认 Docker Desktop 已启动：

```powershell
docker ps
docker compose ps
```

### 12.5 地图无法使用

未配置高德 Key 时属于预期，可在 `frontend/.env` 中补充：

```text
VITE_AMAP_KEY=你的高德地图 Key
```

## 13. 生产化部署建议

当前仓库还不是生产部署形态。若要上线，建议补齐：

- 后端真实数据库 Repository
- Alembic 数据库迁移
- JWT / Session 鉴权
- HTTPS 与反向代理
- 日志采集与异常告警
- Redis 订单锁和通知
- OSS 文件上传
- 支付、退款、申诉、评价审核
- 客服会话持久化
